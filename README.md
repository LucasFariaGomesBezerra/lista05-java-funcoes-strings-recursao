# lista 05 - funcoes, strings e recursao

lista 05 de java. todos os exercicios usam pelo menos um array, uma funcao (metodo que retorna alguma coisa) e um procedimento (metodo void), que era a regra da lista.

- 1 a 5: funcoes, procedimentos e arrays (triangulo, imc, primos, bolha, binario)
- 6 a 8: strings (vogais, iniciais, maior palavra)
- 9 e 10: recursao (potencia e fibonacci)

## como rodar

precisa do jdk 25 por causa do `IO.readln`.

```
javac -d out src/*.java
java -cp out Exercicio05
```

obs: o fibonacci recursivo fica meio lento quando o n chega perto de 30, mas funciona.
